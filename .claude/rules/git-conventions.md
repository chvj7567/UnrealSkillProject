# Git Commit Conventions

## 형식

```
[Tag] ClassName — 변경 내용 요약
```

## 태그 목록

| 태그 | 용도 |
|------|------|
| `[Feature]` | 신규 기능 추가 |
| `[Fix]` | 버그 수정 |
| `[Refactor]` | 동작 변경 없는 코드 개선 |
| `[Debug]` | 디버그용 로그·시각화 추가/제거 |
| `[Chore]` | 빌드 설정, 의존성, 에셋 정리 |
| `[Docs]` | 문서·주석 수정 |

## 규칙

- Task가 끝날 때마다 관련 파일 Stage로만 옮김
- Commit은 하지 않고 커밋 메시지 어떻게 남길지 명시
- `ClassName`은 주로 변경된 클래스 이름 (파일명 아님)
- `—` (em dash) 뒤에 한 줄 요약, 50자 이내
- 여러 클래스를 동시에 수정했으면 가장 핵심 클래스만 명시
- 본문이 필요하면 빈 줄 후 bullet로 작성
